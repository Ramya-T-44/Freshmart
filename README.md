# 🛒 FreshCart – Grocery Shopping Website

FreshCart is a modern and user-friendly online grocery shopping website designed to make everyday grocery shopping simple, convenient, and accessible. The platform allows users to browse grocery products, explore different categories, add items to their cart, and manage their shopping experience through an intuitive web interface.

## 🌐 Live Demo

[Visit FreshCart](https://grocery-shop-website-t2qj.bolt.host/)

## 📌 Project Description

FreshCart provides a digital shopping experience where customers can explore grocery products and conveniently manage their purchases online. The website focuses on a clean interface, easy navigation, and a smooth shopping workflow.

## ✨ Key Features

- 🛍️ Browse grocery products
- 📂 Explore products by categories
- 🔍 Search for required products
- 🛒 Add products to the shopping cart
- ➕ Manage product quantities
- 💰 View product prices and cart totals
- 📱 Responsive and user-friendly interface
- 🎨 Modern grocery-store themed design
- ⚡ Simple and convenient shopping experience

## 🎯 Objective

The main objective of FreshCart is to provide a convenient online platform for purchasing groceries while reducing the effort and time required for traditional grocery shopping.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Modern Web UI technologies
